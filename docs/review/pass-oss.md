**F3 [P2] — CHANGELOG newest-first ordering violated (v0.7.0 buried)**

- Location: `CHANGELOG.md` line 25.
- Issue: `## [0.7.0]` sits **below** `## [0.6.2]` (line 8) and `## [0.6.1]` (line 18); Keep-a-Changelog requires newest first. Also no `## [Unreleased]` section, and the v0.7.0 entry is written in Chinese while all other entries are English.

**F4 [P2] — SBOM/license gate not enforced in CI**

- Location: `.github/workflows/ci.yml` (quality job steps), `package.json` `check` script.
- Issue: Root `pnpm check` ends with `pnpm sbom:gen` (the license gate), but CI runs format/lint/build/typecheck/test **manually and skips the SBOM step**; the gate runs only in the release workflow (`release.yml` "Generate SBOM (CycloneDX)"). So a PR that adds an unlicensed dependency passes CI green and only fails at release time. This overstates the "license-gated in CI" narrative in `README.md`/`CHANGELOG.md`.
- Smallest fix: add `node scripts/generate-sbom.mjs` (or `pnpm sbom:gen`) to the CI quality job.
